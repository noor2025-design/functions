# Project Overview
This was a capstone project for Typography & Interaction class where each student identified a real problem and designed a solution via a website or browser extension. The solution could be meaningful for themselves or others. My project focused on something I often run into which is the overwhleming experience of scrolling through delivery apps and restaurant menus and the decision fatigue that comes with it. A core requirement of the project was that the solution had to include a user input that generates a corresponding output.
## Concept / Process
I initially wanted to build a tool that could recommend restaurants across all of New York City based on factors like mood, budget and location. After discussing the scope of the idea, I was encouraged to narrow my focus significantly either by cuisine or location because I had about 6 weeks to take the project from concept to a fully coded site in HTML, CSS and Javascript. I decided to narrow it down to Arabic cuisine which I chose because it's what I know best and am most personally connected to. I curated my own dataset in a JSON file featuring 6 Arabic cuisines, and while there are many more that I could include, the constraints of the timeline made it necessary to be intentional. As a result, the experience essentially works seamlessly in the amount of time given. The user submits their preferences for cuisine type, price range, and borough and the app generates exactly one restaurant and one dish so that there is no scrolling or overwhelm. Along with the restaurant recommendation, the user gets the restaurant details, a photo of the dish, a description and directions.
## Design System
The design system is minimal which was intentional because functionality was prioritized. I didn't want the visual system to distract from or add to the overwhlem the app is is intended to solve. The color palette is a warm beige, deep terracotta and blush pink which keeps things feeling fun, inviting and approachable. For typography, I chose the New Yorker typeface paired with Libre Caslon Text for body copy which is the same pairing the New Yorker magazine uses in its publication. It's my favorite publication, and to me it represents quintessential New York. I wanted the site to feel a little editorial and curated because food deserves to be carefully selected. Each question gets its own full page to keep the experience clear, focused and easy to navigate. All interactive elements follow a design system. Any button that submits or navigates to a new destination shares the same visual treatment while the next and back navigation buttons use arrow style consistently to distinguish from action buttons. 
## User Experience
Based on user testing feedback, the experience feels seamless from start to finish. The site opens clean and uncluttered with a brief description of what the app does and a single button to get started. The first step presents 6 Arabic cuisine types displayed at a comfortable size, each with a name and image and the selections are highlighted so that the user knows what they've chosen. From there, the next step filters available prices based on only what matches the selected cuisine in the dataset, and the same logic applies in the borough step. Only available options show at each stage based on users selection. Once all preferences are submitted, the user receives their recommendation. The app also allows for flexibility if a user is unsure about any selection and it will still generate a result. Navigation is easy with the ease to go back and forth at any point in the selection process and a progress bar runs throughout the selection flow so users always know where they are in the process and how much further they have to go. The user can also click a button to receive directions to the restaraunt via google maps and would only need to add their location.  If a user wants make changes after receiving a recommendation, there is a reset button to start the process over again which is under 1 min. The site is also fully responsive, offering a consistent experience across both mobile and larger screens.
